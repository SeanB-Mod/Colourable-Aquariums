# GitHub upload

1. Create a separate repository for Colourable Aquariums.
2. Extract this GitHub pack and upload README.md, BUILD.md, CHANGELOG.md, VERSION, RELEASE_NOTES.md, SOURCE_NOTES.md, VALIDATION.md, .gitignore, .gitattributes and src/. Keep release-assets outside the source commit.
3. Create a release tagged v0.7.81.5, titled Colourable Aquariums v0.7.81.5.
4. Paste RELEASE_NOTES.md into its description.
5. Attach the Windows-x64 ZIP and its .sha256 file from release-assets/.

The GitHub pack is for maintaining the source repository. Players should download the Windows-x64 release ZIP. Nothing has been uploaded or published automatically.
