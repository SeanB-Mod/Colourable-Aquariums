# Source notes

This pack contains the source needed to build this project's DLL and its isolated tests. No game assemblies, extracted API dumps, toolchain binaries, player saves or logs are included. The source is supplied without assigning a new license; an owner-selected license can be added to the repository.

The source retains historical implementation comments and internal POC naming for provenance. This release includes the focused release changes listed in CHANGELOG.md; it is not the previously approved DLL.

Builds were verified using LLVM-MinGW clang 22.1.8 (20260616 UCRT x86_64 distribution) and Python 3. Build scripts accept local toolchain paths.
